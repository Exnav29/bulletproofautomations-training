Credentials — the register behind /verify

Issuing a credential here makes it verifiable immediately at training.bulletproofautomations.com/verify. Revoking never deletes: a deleted row reads as “never issued”, which is the one thing revocation must not look like.

Manual credential issuance (advanced)

Issue a credential

An issued credential is a real thing in the world. Undoing one means revoking it, which stays on the record — so this asks twice.

Bulk PDF archive and recovery

Archive issued PDF certificates

Select one or more completed certificates. Each filename must be its exact registered ID, for example BPA-FND-2026-WHXRTT.pdf. The server saves the PDF and automatically creates its preview before linking both files to the existing credential record. No credential is issued and no email is sent by this action.

Repair certificate previews

Generate missing previews automatically from archived PDFs. No additional files are needed. Existing PDFs and private masters are preserved.
